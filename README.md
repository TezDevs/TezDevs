## 🎨 Brand Direction

**Digital Hooligan** blends minimal luxury design with cyberpunk energy.

### Color Principles
- Onyx Black (#111111)  
- Rebel Red (#FF3131)  
- Electric Mint (#1EFFCB)  
- Graffiti Yellow (#FFC700)  

### Design Philosophy
- Structured layouts  
- Iconic typography  
- Clean neon highlights  
- Emotion through simplicity

### 🌑 Dark Mode vs 🌕 Light Mode

**Dark Mode (Primary)**  
- Background: Onyx Black / near-black  
- Accents: Electric Mint, Circuit Blue, Rebel Red  
- Feel: Terminal, focused, cinematic  

**Light Mode (Secondary)**  
- Background: Off-white / very light gray  
- Accents: Rebel Red & Mint for contrast  
- Feel: Editorial, portfolio, presentation-friendly  

Digital Hooligan lives mostly in **dark mode**, with light mode reserved for documentation, case studies, and clean presentation surfaces.
